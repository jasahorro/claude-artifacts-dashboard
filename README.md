## Introducing Today's Project!

In this project, I'm going to build an interactive dashboard from a CSV dataset using Claude.ai Artifacts to visualize spending trends with interactive charts, summary tiles, category filters, and custom themes without writing any code.

### Key tools and concepts

Key tools used: Claude.ai for interacting with Claude Sonnet via natural language prompts, the Claude Artifacts side panel for rendering and testing interactive visual outputs, and Recharts—a composable React charting library compatible with the Artifacts runtime—for building custom charts and dynamic data visualizations directly from raw CSV data.

Key concepts learnt: The render-iterate loop, which enables modifying artifacts in real time using conversational prompts; the artifact version selector for comparing and switching between previous iterations; and shared state management, which seamlessly powers interactive dashboard features like category dropdown filtering, hover tooltips, dynamic chart updates, and dark/light mode toggles across all components.

### Challenges and wins

This project took me approximately 30 minutes to complete, from initial setup to publishing the final dashboard link.

The most challenging part was formulating clear, structured prompts when adding interactive features—like the category filter and dark/light mode toggle—to ensure Claude updated the existing Recharts artifact smoothly in place without breaking the dashboard's layout or data links.

### Why I did this project

I did this project today to learn how to use Claude Artifacts to convert raw CSV data into an interactive, published React dashboard with customized themes, charts, and dropdown filters using plain English prompts without writing code.

Another skill I want to learn is how to build AI-powered workflows and integrate LLM APIs directly into web applications to process dynamic user data in real time.

Claude.ai is an AI assistant platform by Anthropic where users can interact with Claude using natural language to perform tasks like text generation, coding, analysis, and rendering interactive visuals using Artifacts.

### Where Artifacts appear

Artifacts are substantial, self-contained pieces of content—such as code, HTML pages, React components, SVGs, or formatted documents—generated by Claude that you can view, iterate on, or reuse.

They appear in a dedicated side panel to the right of your main chat window, rather than inline within the conversation.

When I sent the follow-up prompt, the artifact updated in place with the new warm gradient background and welcome text instead of opening a brand new chat or separate panel. I noticed the version selector showed that a new version was stacked on top of the original, allowing me to flip back and forth between previous and current versions of the artifact.

This render-iterate loop is useful because it allows you to refine and modify your work in plain English without losing context, writing manual code, or managing multiple separate files.

## Turning a CSV into an Interactive Dashboard

In this step, I'm pasting a sample CSV dataset into Claude.ai along with a structured prompt to build an interactive React dashboard using Recharts, complete with summary tiles, bar and pie charts, and hover tooltips.

### Why this CSV

The CSV has personal finance and spending data with headers for date, category, amount_usd, and notes.

Claude needs it because LLMs read messages sequentially top-to-bottom; providing the dataset directly with the prompt gives Claude the exact raw data to aggregate, structure, and visualize into the React dashboard without hallucinating or inventing extra rows.

![Image](https://nextwork.ai/overjoyed_magenta_proud_yak/uploads/881a1a03-2930-5b13-b381-0a030dd6e48e_d5n1f7b9)

### Why Recharts

Recharts is a popular composable charting library built with React and D3 components that is pre-loaded and supported directly within the Claude.ai Artifacts React runtime.

We named it because specifying Recharts directly in our prompt ensures Claude uses a library that is fully supported and ready to render in the Artifacts environment, preventing runtime errors or attempts to load unsupported external charting packages.

![Image](https://nextwork.ai/overjoyed_magenta_proud_yak/uploads/881a1a03-2930-5b13-b381-0a030dd6e48e_y4c1m8t5)

### Making the dashboard interactive

I could hover, click, filter, and interact with the data in real-time. What surprised me was how quickly Claude turned raw CSV data into a fully dynamic React component using Recharts, giving me built-in tooltips, legend toggles, and responsive filtering from just a single natural language prompt without writing a single line of code.
